#+title: claude-code-kde-focus
#+author: Berdan Akyürek

Brings your terminal window and the correct tab to the foreground whenever
Claude Code finishes a task or asks for approval — just like how a debugger
pops up when it hits a breakpoint.

Works with any terminal on KDE Wayland. Tab switching is supported for
Konsole, Kitty, and WezTerm. Other terminals (Alacritty, foot,
xterm, etc.) still get window focus, just without tab switching.

* Requirements

- KDE Plasma 6 on Wayland
- =kdotool= — KDE Wayland window management tool
- =qdbus= — Qt DBus utility (Konsole tab switching)
- =jq= — JSON processor
- =kwriteconfig6= — KDE config writer

* Install

#+begin_src shell
git clone https://github.com/berdanakyurek/claude-code-kde-focus
cd claude-code-kde-focus
./install.sh
#+end_src

The installer will:

1. Check all dependencies
2. Copy =claude-focus.sh= to =~/.local/bin/=
3. Register =Stop= and =Notification= hooks in =~/.claude/settings.json=
4. Set KDE Focus Stealing Prevention to =None= via =kwinrc=

* Uninstall

#+begin_src shell
./uninstall.sh
#+end_src

Removes the script, cleans up the Claude Code hooks, and restores
KDE Focus Stealing Prevention to its default (Medium).

* How it works

Claude Code supports shell hooks that fire on specific events.
This project hooks into two of them:

| Hook           | When it fires                              |
|----------------+--------------------------------------------|
| =Stop=         | Claude finishes a response                 |
| =Notification= | Claude is waiting for approval or input    |

When either hook fires, =claude-focus.sh= does the following:

1. Walks up the process tree (PPID chain) to find the terminal emulator's
   window, then uses =kdotool windowactivate= to bring it to the foreground
2. Switches to the correct tab using a terminal-specific method:

| Terminal       | Method                         | Detection                  |
|----------------+--------------------------------+----------------------------|
| Konsole        | =qdbus setCurrentSession=      | =$KONSOLE_DBUS_SERVICE=    |
| Kitty          | =kitty @ focus-window=         | =$KITTY_LISTEN_ON=         |
| WezTerm        | =wezterm cli activate-pane=    | =$WEZTERM_PANE=            |
| Other          | window focus only              | —                          |

3. Sends a desktop notification via =notify-send=

Terminal detection is based on environment variables injected by each
terminal into its child processes, so if multiple terminals are running,
the one that launched Claude Code is always targeted correctly.

** Kitty setup

Kitty tab switching requires remote control to be enabled. Add to =~/.config/kitty/kitty.conf=:

#+begin_src
allow_remote_control yes
listen_on unix:/tmp/kitty-{kitty_pid}
#+end_src

* Why kdotool?

On KDE Wayland, =xdotool= and =wmctrl= do not work for native Wayland windows.
=QWidget::raise()= via DBus does not steal focus either due to compositor
security restrictions. =kdotool= uses the =kde-plasma-window-management=
Wayland protocol, which KWin exposes specifically for this purpose.

KDE's Focus Stealing Prevention must be set to =None= for =kdotool windowactivate=
to actually bring the window to the foreground.
